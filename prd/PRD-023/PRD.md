## 0. 使命(2026-08-08 用户原话定)

**解决老师拿不到想要的题的问题;解决老师出不了好题的问题;解决老师备课资料的问题。**

## 1. 三大定案(凌驾一切实现细节)

1. **SQLite 是唯一参照物**(`举一反三产物/资料库.db`)。文案/网盘/状态/题目全在库;md/产线卡降级为历史档。
2. **状态现算不存两份、体检提醒不拦路、脏活给 agent**(v4 地基三句,由 40 洞审计倒推)。
   只存 3 个状态字段(task.状态 / doc.人工态 / question.实算),泳道与"可发布"全为现算查询;发布台口径=**拦新不拦旧**。
3. **六类资料一张 doc 表**:专项·试卷·讲义·练习册(=母题池,Word 录入)/ 课本(图片 PDF,只挂档不拆题)/
   打卡(=母题的举一反三派生,**通式可复现**:mother_id 指母题 + generator_id 记通式)。Word 是操作台,PDF 是产物。

## 2. 范围

### v2-M1(本批,先能用)

- Schema 7 表(设计稿附二):doc / question / collection_item / material / asset / task+generator / publish_log。0 触发器。
- **存量导入(轻)**:25 册打卡元数据+物料从 v1 产线卡/解析结果直搬(book/material/asset 行);
  三升四 620 题(days JSON 已结构化)直搬入 question 当检索种子——**不属深度处理**。

  python venv sidecar `embed.py`;向量存 question BLOB 列,几千题暴力余弦)。🔴 与 PRD-021(线上 pgvector)互挂指针不合并。
- 页面 M1:资料库 / 册详情(四项体检现算)/ 题目库(三路检索+考点覆盖地图)。

### v2-M2(紧随)
